# Human data

Raw human choices from Mei, Xie, Yuan & Jackson (2024, PNAS), copied unchanged from Mei et al.'s repo
[yutxie/ChatGPT-Behavioral](https://github.com/yutxie/ChatGPT-Behavioral) at commit
`69ec5575efc373382de5bfc6e457667c2d0b3e60` (MIT licence, see LICENSE). Mei et al. describe the
columns in `File Description.pdf` in that repo.

| file | game |
|---|---|
| dictator.csv | dictator |
| ultimatum_strategy.csv | ultimatum (proposer and responder) |
| trust_investment.csv | trust (investor and banker) |
| public_goods_linear_water.csv | public goods |
| bomb_risk.csv | bomb risk |
| push_pull.csv | prisoner's dilemma |
